# DERDAB COMPTA – Cabinet d'Expertise Comptable, d'Audit & de Conseil

Site web officiel du Cabinet **DERDAB COMPTA**, dirigé par **Maître Mourad Derdab**, membre de l'Ordre des Experts-Comptables du Maroc (OEC).

Implantations : **Tanger City Center**, **Tanger Free Zone (TFZ) & Tanger Automotive City (TAC)**, **Tétouan Wilaya Center**, et **Tanger Med Port & Logistics**.

---

## 🚀 Déploiement Direct sur Vercel

Le projet est configuré avec un fichier `vercel.json` prêt pour la production (support SPA routing, cache des assets statiques) :

1. Connectez votre dépôt GitHub à [Vercel](https://vercel.com).
2. Sélectionnez le dépôt `derdab-compta`.
3. Framework Preset : **Vite**.
4. Build Command : `npm run build`.
5. Output Directory : `dist`.
6. Cliquez sur **Deploy**.
